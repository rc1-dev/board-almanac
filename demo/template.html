Almanac

Which rule applies now, since when, and on whose authority?

A versioned, cited rulebook for HOA, condo and club associations, compiled from their records on the NAS.

ReplayThis page replays the expected behavior of the almanac Skill on a synthetic archive for a fictional 48-unit building. The Skill is designed to run on a UGREEN AI NAS, and results from the device will follow the hackathon's device testing. The delegation text is quoted from the Skill, and the answers are the reference answers from the validation kit.

The board folder

The archive covers seven years of bylaws, minutes, notices, a contract, an email and a meeting recording. Several files were written to test how the Skill handles errors, proposals and conflicting statements. Select a file to read it.

    The Skill delegates every step to the UGOS agents. It never asks them to overwrite, move or delete a file, and nothing is saved until the user has reviewed each changed rule.

      The almanac

      Each compile produces one Markdown file. For every topic it records the documented rule, the vote or document that established it, a quotation and the rules it replaced.

        Open the file

        Ask

        Answers are drawn only from the newest almanac and cite the source file and almanac version. For several questions, a typical answer from a search of the raw folder is shown alongside, and both are scored with the same answer key.

        Update: version 2

        When new minutes arrive, the next compile takes a new snapshot, reads every document again, builds version 2 from them alone, compares it with version 1 to write the changelog, and saves it beside version 1. Nothing is carried over from version 1 except its version number and the summary used for comparison.
