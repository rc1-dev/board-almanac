The board folder

Seven years of bylaws, minutes, notices, a contract, an email and a meeting recording. Later votes replace earlier ones, and a few files are traps. Pick a file to read it.

    Compile: version 1

    The Skill only delegates to UGOS experts. It never overwrites, moves or deletes a file, and it asks before creating the folder and before saving.

      The almanac

      One Markdown file per compile run. Each topic keeps the current rule, the vote or document that set it, a quote, and every rule it replaced.
